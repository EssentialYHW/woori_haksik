# 우리학식

학교 홈페이지의 학식 메뉴를 모아 보여주는 안드로이드 앱이에요.

> **현재 버전: 0.1.0 (프로토타입)**
> 기능과 화면이 계속 바뀔 수 있는 테스트 버전이에요.

## 기본 기능

- **학교 선택**: 학교를 고르면 앱이 그 학교의 상징색으로 바뀌어요.
- **오늘 학식**: 캠퍼스별 식당 메뉴와 가격, 운영 상태(운영 중 · 휴게 중 · 오픈 시간 · 영업 종료)를 보여줘요.
- **날짜 선택**: 이번 주 다른 날 메뉴도 볼 수 있어요.
- **주간 메뉴**: 식당별로 월~금 메뉴를 한 번에 볼 수 있어요.
- **즐겨찾는 식당**: 즐겨찾기한 식당을 화면 맨 위에 크게 보여줘요.
- **오프라인 보기**: 인터넷이 없어도 마지막으로 받은 메뉴를 보여줘요.
